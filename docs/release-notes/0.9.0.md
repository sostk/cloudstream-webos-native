## What's new in 0.9.0

### Live TV
- **Live DASH streams no longer start buffering after a few seconds.** Playback now starts as far
  behind the live edge as the stream asks for, the way CloudStream's player does. Before, it
  started about 4 s from the edge, fetched video that was still being written, kept dropping the
  quality and then stalled (PlayZTV live events and other DASH channels,
  [#39](https://github.com/sostk/cloudstream-webos-native/issues/39)).
- **Links that point at a playlist without saying so now play.** When a plugin marks an HLS or
  DASH playlist as a plain video, the player checks what the server sends and plays it as a
  stream. Ordinary video files are unaffected and make no extra request.

### Plugins
- **Escaped link URLs are cleaned up.** Links that arrive as `https:\/\/…` (copied out of JSON
  without decoding) now open. This applies to video, audio, subtitle and licence URLs.

### Looks
- **Symbols in provider names and row titles show up.** The app bundles Noto Emoji, so titles such
  as 🏏 Cricket and 🥊 Boxing no longer start with an empty box on TVs with older system fonts.

### Privacy
- **Logs hide tokens in URLs.** Media log lines mask URL path segments that are tokens
  (`https://<cdn>/<redacted>/v.mp4`), so `events.log` is safer to attach to an issue.

### Also in this release
- Native App Kit: Starfish playback recognises its load-complete event by number as well as by
  text.

### Known issues
- Some VidHide mirrors refuse TLS connections from certain networks; the plugin's other mirrors
  play.
